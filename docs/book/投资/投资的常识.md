# 投资的常识 - 十周年纪念版

> data: 2026-08-02

## 复利的威力
- 72法则： 年收益率8%，则9年可以将资产翻一倍，18年两倍，27年4倍
- 储蓄越早开始越好

## 不要碰高息负债，利滚利还不清
- 信用卡每次最低还款，堆积的本金越来越高，而且利息也会随着复利增加，无法预测什么时候要让你一次全额还清（强制性）

## 储蓄的办法
- 合理避税
- 有目的性的购物，即省钱也节省时间

## 投资
- 投资指数基金比主动性基金更安全也更长久
- 长期来看，越宽泛的指数基金长期看收益更高，如标普500收益率会低于罗素3000
- 多元化配置+股债再平衡策略：不要只投一个国家指数基金，每年要做一次股债再平衡，保证比例是预期
- 选择管理费低的，多出来的就是你的收益
- 定投能保障你的长期收益，在低位增加定投金额，在高位减少定投金额，此为长久之道
- 减少错误的发生就是往好的上发展：不要买看不懂，不要去追热点，这种短期可能收益高，但会让你容易犯错误导致长期亏损

## 个人风险承受
- 保持稳定的现金流，让你能更长久的活下去，至少保留半年的开销的现金流
- 越年轻越应该投资指数基金，但是也要看个人承受力，如果腰斩了是否能吃好+睡好。股债比可以从100:0开始，减少股，增加债，来保障睡好。
- 购买银行的存款储蓄可以问下有没有存款险，保障自己安全
- 购买商业保险，医疗险，重疾险，寿险，年金，意外险，车险等等，要考虑用途在决定是否购买
