# 我的投资总结

---

## 交易原则
- 止盈： 低位买，最多-5%~-7%。 有盈利，最低也要保本走。
  - 买入后就要挂条件单做止盈止损
  - 高位高换手、爆量当天必走
  - 高位横盘五个交易日就要走了或者减仓
  - 永不对亏损头寸加仓。任何一笔交易，买入后若从未盈利超过3%，禁止进行第二次买入。你唯一的补仓机会， 是在首次建仓后，股价已脱离成本区，证明你的判断正确，且回踩关键支撑企稳时，才可按计划加仓一次。
  - 禁止在主线仓位上做T
  - 单只个股总仓位永不超过60%
- 选股： 市场热度+趋势走势+业绩确定性+行业壁垒强度
  - 口袋支点（放量大阳突破关键均线）
  - 确认趋势中的首次缩量回踩10/20日线
  - 解禁/减持一票否决
- 

## 人性
- 持续盯盘，就像注视深渊

## 市场
- 悲观更容易让人接受，同时也有可能是陷阱，让你停止做某些事

## 我要做的
- 复利只有长期且不间断的做才有效
- 保持稳定现金流是为了让你不会被迫买出希望长期持有的股票

## 历史复盘
- 浙江建投： 持股10个月，越跌越补，亏损21.82% (3785/17362)
  - 买入动机： 高位回撤幅度大，到前低位置，预期反弹
    - 多次补仓动机： 摊平成本，希望回本
  - 卖出动机：亏损幅度增加，下跌趋势无改
  - 思考：前低越来越低，就是下跌趋势了，应该马上止损
- 南京商旅： 持股四十天，一次打满，亏损18.22% (3810/20911)
  - 买入动机： 均线杂糅，进行博弈
  - 卖出动机： 长期下跌趋势形成
  - 思考：均线杂糅无法向上应该马上止损
- 永辉超市：持股8个月，从盈利30%+，一直补仓，最后亏损15(15439/10w)
  - 买入动机：五板之后跌了30%+，认为是机会，跌了就补，后面拉起来了，也在补，一直卖/T
  - 卖出动机：做T降低成本，股价翻3倍后，高位开始回调，感觉市场风格有切换，止损了
  - 思考：不能在大涨之后上仓位，应该边涨边卖出，最后让利润奔跑
- 洛阳钼业： 持股4个月，从盈利10%+，高位做T/补仓，最后亏损7.17% (7179/10w)
  - 买入动机：市场金属炒了三个，仍然在涨，认为是机会，回踩20日线入，连续三天在20日线下出，两日突破20日线后再入
  - 卖出动机：从高点回调了28%, 外围环境变化，战争导致加息预期，扛不住了，虽然觉得金属长期还是有希望，但是股价从低点翻了快5倍，风险也很大。
  - 思考：交易频繁，出手次数偏多，做T失败导致成本增高，无法分辨中回调是短期还是长期，以及高位爆量阴线不走。
- 化工ETF鹏华： 持股两个月，亏损6.7% (6706/10w)
  - 买入动机：战争导致化工涨价逻辑，低于20日线补仓，高位阴线也补（长期看好）
  - 卖出动机：连续八个阴线，放量到缩量到温和放量，补仓导致仓位高，波动心态不好
  - 思考：没有在关键点位入手，而且最后没有破最后的支撑位，倒在黎明前，后面拉起来
    - 深度： 借钱加了杠杆导致高持仓心态不稳，没有等到合理的位置就乱动
- 牧原股份： 持股两个月，从5%的盈利到-13.8%+ (4981/3.6w)
  - 买入动机：猪周期预期，先入一层，跌8%就继续补
  - 卖出动机：下跌趋势明显，其他热度高感觉猪肉没那么快调整好，先撤了。
  - 思考： 预期要和实际走势和市场热度相结合，不然越买越跌，越跌越买，持仓不利
- 鸿博股份： 持股四十天
  - 买入动机： 底部反转博弈，做T、5日线下买入
  - 卖出动机： 回撤30%+，觉得趋势坏了
  - 思考： 压力位爆量+高换手没出，后续还在补，身在其中，存有幻想，没想懂止损。 高位涨停板+高换手，第二天直接跌，走势不明确的，应该执行严格的止盈位置
- 恒生医药ETF华夏： 持股三个月，T0所以进场做日内T，但是亏损概率大。 亏损7.7% (7709/10w)
  - 买入动机：涨了八个月，确定性强，又是t0，可以跑很快
  - 卖出动机：下跌趋势明显，成本T的越来越高
  - 思考：T0不是用来炒日内的，容易着急加或者卖，一下想等明天，一下想马上出，难以有效决策。高位横盘超过一个月了，还不走，就是要憋了。
